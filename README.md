# Personal Portfolio Website

A responsive personal portfolio website developed using HTML5 and CSS3. The website presents my academic background, technical skills, projects, experience, hobbies, and contact information in a clean and professional layout.

## 📌 Project Overview

This project was developed as part of my web development internship to strengthen my frontend development fundamentals and gain practical experience in building a complete website from scratch.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Home section with personal introduction
- About Me section
- Technical Skills section
- Education section
- Projects section
- Hobbies & Interests section
- Contact section
- Navigation using internal page links
- Hover effects and responsive layouts
- Clean and structured user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub
